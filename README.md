## 🚀 Featured Project

### ForumX — Reddit-Inspired Application

ForumX is a personal software development project focused on building a social platform with a structured REST API backend.

The backend is developed using **PHP 8.1, MySQL, and PDO**, with an emphasis on application architecture, authentication security, and maintainable code.

**Key technical highlights:**

- **Layered architecture** — separating request handling, business logic, and database access.
- **JWT authentication** — implementing access and refresh tokens with token rotation and session management.
- **Session security** — supporting session revocation, logout, and logout across multiple sessions.
- **Authorization** — enforcing permissions and access restrictions.
- **Core platform functionality** — users, subreddits, posts, comments, subscriptions, and moderation.
- **API testing** — validating application behavior through Postman and automated tests.

**Current status:** Backend implemented. Android client planned.
